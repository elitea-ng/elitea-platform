# office-core fuzz targets

`cargo +nightly fuzz run fuzz_deck` (also `fuzz_document`, `fuzz_workbook`,
`fuzz_gate`) from this directory. Seed with any pptx, docx or xlsx files; the
hostile corpus is generated by `tests/hostile.rs` and replayed, bounded, by
`tests/corpus.rs` on every CI run. ADR-0032 asks for 10 minutes per target
without a panic, abort or out-of-memory; CI does not run these (they need
nightly and libFuzzer), the release gate does.
