- **Ready to chat?** Go straight to [Chat quick start](/getting-started/chat-quick-start).
- **Connecting an external tool?** See [Connect toolkits quick start](/getting-started/connect-toolkits-quick-start) or the [toolkit catalogue](/reference/toolkit-catalogue).
