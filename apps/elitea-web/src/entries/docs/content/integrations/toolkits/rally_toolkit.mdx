Read and manage Rally (Broadcom Agile Central) user stories and iterations. It's listed under the **project management** category in the toolkit type picker.

## Prerequisites

- An account at Rally with permission to issue an API token or credential, saved in Elitea as a **`rally`** credential (`/credentials/create-credential/<type>`).

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **project management** category, or search for "Rally".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **rally** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>

## Common issues

<Note>
On the Python worker (the compose standalone default), `Rally` fails to import and the tile is hidden (tracked in #869). Use a deployment running the Rust worker to connect Rally.
</Note>

<Note>
There's no connection check on this form. Save the toolkit, then run one read-only tool from the editor's Test tools pane to confirm the credential works before attaching Rally to an agent.
</Note>
