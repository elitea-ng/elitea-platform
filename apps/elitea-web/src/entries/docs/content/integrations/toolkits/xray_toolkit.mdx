Read and manage Xray Cloud test executions and results, stored against Jira issues. It's listed under the **test management** category in the toolkit type picker.

## Prerequisites

- An account at XRAY Cloud with permission to issue an API token or credential, saved in Elitea as a **`xray`** credential (`/credentials/create-credential/<type>`).
- If you plan to index content for retrieval: a `pgvector` credential and an embedding model, configured under AI providers.

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **test management** category, or search for "XRAY Cloud".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **xray** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Add indexing settings (optional)">
If you plan to index this source, set an **embedding model** and a **pgvector** credential. Leave both empty to use the toolkit without indexing.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>

## Common issues

<Note>
On the Rust worker, this tile shows greyed out with a reason — the Rust worker does not materialise `XRAY Cloud` (tracked in #865). Helm now defaults to the Python worker, matching compose (#865, #866); a deployment that opts into the Rust worker still needs the Python worker to connect XRAY Cloud.
</Note>

<Note>
The Indexes tab only appears when the configured worker can run this type's `index_data` tool; if the worker can't, the tab is hidden and shows the worker's refusal message. `index_data` itself can't be run from the Test tools pane — use the Indexes tab.
</Note>

<Note>
There's no connection check on this form. Save the toolkit, then run one read-only tool from the editor's Test tools pane to confirm the credential works before attaching XRAY Cloud to an agent.
</Note>

<Note>
The saved-credential type for this toolkit is named **`xray`**, not `xray_cloud` — pick `xray` when creating the credential.
</Note>
