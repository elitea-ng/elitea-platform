Read SonarQube/SonarCloud code-quality issues and metrics. It's listed under the **development** category in the toolkit type picker.

## Prerequisites

- An account at Sonar with permission to issue an API token or credential, saved in Elitea as a **`sonar`** credential (`/credentials/create-credential/<type>`).

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **development** category, or search for "Sonar".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **sonar** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>
