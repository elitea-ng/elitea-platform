Run and inspect requests from a Postman collection. It's listed under the **other** category in the toolkit type picker.

## Prerequisites

- An account at Postman with permission to issue an API token or credential, saved in Elitea as a **`postman`** credential (`/credentials/create-credential/<type>`).

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **other** category, or search for "Postman".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **postman** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>

## Common issues

<Note>
Both the Rust and Python workers materialise `postman`; this toolkit works the same regardless of which worker your deployment runs.
</Note>

<Note>
The credential form for Postman supports **Check connection** — use it before saving to confirm Elitea can reach Postman with these details, instead of discovering an auth problem from a failed tool call later.
</Note>
