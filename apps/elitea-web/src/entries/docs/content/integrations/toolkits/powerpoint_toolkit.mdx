Create and edit PowerPoint presentations, saved as artifact files. It's listed under the **office** category in the toolkit type picker.

## Prerequisites

- No credential is required to add PowerPoint — its settings only configure behaviour, not authentication.

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **office** category, or search for "PowerPoint".
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>
