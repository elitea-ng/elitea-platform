As a project accumulates agents, pipelines, toolkits, credentials, and MCP connections, four features keep the catalogue navigable: search, tags, pins, and folders.

## Search

The Agents, Pipelines, Toolkits, Credentials, and MCPs pages each have a search box that matches on name and description, and lets you filter by tag. Type into the box to see matching results grouped by tag and by entity type; select a result to open it directly.

<Screenshot id="entities-search-and-tags" alt="Agents list with the search box open and tag chips visible" />

## Tags

Tags are free-form labels you attach to an entity to group it by topic, team, or project. Add one from the entity's configuration:

<Steps>
1. Open the entity's configuration.
2. Find the **Tags** field and start typing.
3. Select a suggested tag or press Enter to create a new one.
4. Save the entity.
</Steps>

Tags are shared within a project — anyone with search access can filter by them, which is what makes them useful for grouping work across a team.

## Pins

Pinning keeps an entity at the top of its list, across sessions, so you don't have to scroll or search for something you use constantly. Pin and unpin with a single click from an entity's list row; pinning works for agents, pipelines, toolkits, credentials, and MCPs.

<Screenshot id="entities-pin-action" alt="Entity list row with the pin action highlighted" />

## Folders

Folders group conversations in the chat sidebar — this is new in this platform (the legacy site had no equivalent). Create a folder from the conversation list, then drag conversations into it, or move a conversation into a folder from its context menu.
