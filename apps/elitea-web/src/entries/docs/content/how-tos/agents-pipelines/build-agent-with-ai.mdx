---
title: "Build an agent with AI"
description: "Describe an agent in plain language and let Elitea generate a starting draft you review before it is created."
---

Build with AI turns a short, natural-language description into a starting agent draft — name, description, instructions, welcome message and conversation starters. Nothing is created until you review the draft and confirm.

## Generate a draft

<Steps>
<Step title="Open the form">
Go to **Agents**, click **Create**, and open the **General** section of the new agent form.
</Step>
<Step title="Open Build with AI">
Click **Build with AI** (sparkle icon) in the section header. The button only appears if you have permission to create or update agents in the project, and the project has a default LLM model configured.
</Step>
<Step title="Describe the agent">
Enter what the agent is for, what tasks it should handle, and any tone or constraints you want. Press **Enter** to generate (Shift+Enter adds a line break instead).
</Step>
<Step title="Review and edit">
Elitea returns a draft with **Name** (up to 32 characters), **Description**, **Instructions**, **Welcome message** (up to 768 characters) and up to four **Conversation starters**. Every field is editable before you create the agent. Use **Back to prompt** to revise your description and regenerate.
</Step>
<Step title="Create the agent">
Click **Create Agent**. The agent is created with the reviewed fields and the project's default model, and the page opens on its Configuration tab for further setup.
</Step>
</Steps>

<Screenshot id="build-agent-with-ai-dialog" alt="Build with AI dialog showing the description input step" />

<Note>
The review form also shows **suggested toolkits, MCPs, pipelines, agents, and skills** below the text fields, when the project has any that plausibly relate to the description you gave — a name/description match against the new draft, not an exhaustive search. Check the ones you want; unchecked suggestions are simply not shown, not hidden-but-attached.
</Note>

<Note>
Suggested **agents** and **pipelines** are attached to the new agent when you check them and create it. Suggested **toolkits**, **MCPs**, and **skills** can be checked in the review form, but attaching them is not wired yet — checking one has no effect once the agent is created (tracked in [#881](https://github.com/elitea-ng/elitea-platform/issues/881)). Attach a toolkit, MCP, or skill from the agent's own Configuration tab after creating it instead.
</Note>

The same generator is available for a skill (`/skills/create`) and for project context (Settings › public project context) — the underlying draft endpoint serves all three, so the same "describe it, review it, create it" flow applies there too. See [Create and share a skill](/menus/skills).

## Edit instructions with AI

Once an agent exists, its Configuration tab's General section can show an **Edit with AI** button next to the Instructions field. It needs a model configured on the agent's version and an AI configuration the deployment has enabled; if either is missing, the button does not appear at all rather than failing on click.

<Steps>
<Step title="Open the editor">
Click **Edit with AI**.
</Step>
<Step title="Describe the change">
Enter what you want changed about the instructions — for example, tightening scope or changing tone.
</Step>
<Step title="Review the diff">
Elitea proposes replacement instructions and shows a highlighted diff against the current text.
</Step>
<Step title="Apply">
Applying the suggestion fills in the Instructions field, the same way any manual edit would. Save the agent version afterward to keep the change.
</Step>
</Steps>

This tool edits **instructions only** — it does not touch the name, welcome message, conversation starters, or attached toolkits/skills, and it has no separate "save as version" step of its own; use the agent's normal version controls for that (see [Version agents and pipelines](/how-tos/agents-pipelines/entity-versioning)).

<Note>
A chat conversation's "+" menu can also create a new agent directly, alongside attaching an existing one — it opens the same inline editor as `/agents/create`, and saving attaches the new agent to the conversation automatically. See [Create and edit agents, pipelines, toolkits and MCPs from chat](/how-tos/chat-conversations/create-entities-from-chat).
</Note>
