title: "Use canvas"
description: "Edit a code block, table, or diagram from an assistant's reply in a dedicated collaborative editor."
---

Canvas turns a code block, table, or Mermaid diagram from an assistant's reply into its own editor, so you can refine it without leaving the conversation.

## Open canvas

Ask a model to generate something canvas supports — a script, a Markdown table, or a Mermaid diagram — then click the edit (pencil) icon that appears on that block. This opens the canvas editor for just that piece of content.

<Tabs>
<Tab title="Code">
Syntax-highlighted editing with its own undo/redo history. Use **Copy** to copy the current content to your clipboard, or **Save** to persist your edits back to the conversation.
</Tab>
<Tab title="Table">
A spreadsheet-like view over the Markdown table. Edit cells directly, then **Save**, or export the table to CSV or XLSX.
</Tab>
<Tab title="Diagram">
Edit the underlying Mermaid source with a live preview, then **Save**.
</Tab>
</Tabs>

## Real-time collaboration

If more than one person has the same conversation open, everyone sees who else is editing a canvas at the same time — canvas is a collaboratively edited block, not a private draft.

## Closing and reopening a canvas

Closing the canvas panel doesn't discard your edits as long as you've saved — the block in the conversation updates with your latest saved version. Reopening the same block later (by clicking its edit icon again) picks up where you left off, since it's editing the message's content directly rather than a separate draft.

## Open a stored file in canvas

Canvas isn't limited to blocks generated in the current turn — it can also open a previously stored text-like file (code, Markdown, CSV/TSV, or Mermaid), from two places:

- **A message attachment.** Hover a text-like attachment card in the conversation and click its **Open in canvas** icon.
- **An artifact bucket file.** In [Artifacts](/menus/artifacts), open a file's preview and click **Open in canvas** in its toolbar.

Either way, the file's content loads into the same editor described above — code gets syntax highlighting, a `.csv`/`.tsv` file opens as a table, and a `.mmd`/`.mermaid` file opens as a diagram with a live preview. Files over 2 MB, and non-text kinds such as images or `.docx`, aren't opened in canvas.

## Save to artifacts

The canvas header's **Save to artifacts** button (the floppy-disk icon) writes the current document to the artifact store — this works whether the canvas was opened from a stored file or generated in the current turn. Choose a bucket, confirm or change the filename (a canvas opened from a file starts pre-filled with the same bucket and name), and save. If a file with that name already exists in the chosen bucket, you're asked to confirm the overwrite; saving back to the SAME file a canvas was opened from skips that confirmation, since that is the ordinary re-save. After saving, further saves from that canvas update the same object.
