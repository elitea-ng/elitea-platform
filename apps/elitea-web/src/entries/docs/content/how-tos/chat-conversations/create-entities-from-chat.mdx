title: "Edit agents, pipelines, toolkits and MCPs from chat"

---

Once an agent, pipeline, toolkit, or MCP connection (an MCP connection is a kind of toolkit) is a participant in your conversation, you can open its editor inline and adjust it without switching pages. This page covers editing an existing participant — creating a brand-new one still happens on its own create page, outside chat.

## Edit an existing participant

<Steps>
<Step title="Attach the participant">
If it isn't already in the conversation, attach it from the composer's **+** menu or by typing `#`. See [Use chat](/how-tos/chat-conversations/how-to-use-chat-functionality#attach-participants).
</Step>
<Step title="Open its editor">
Click the participant in the **Participants** panel, then click its settings icon (or hover and click the edit icon that appears).
</Step>
<Step title="Make your changes and save">
The inline editor opens for that entity type. Edit it and save — the change applies to that entity going forward, the same as editing it from its own page.
</Step>
</Steps>

<Screenshot id="chat-agent-inline-editor" alt="Chat with an agent's inline editor panel open on an existing participant" />

## What you can change per entity type

- **Agent**: instructions, model and model settings, and attached toolkits. See [Build an agent with AI](/how-tos/agents-pipelines/build-agent-with-ai) for the underlying fields.
- **Pipeline**: the flow and its nodes. See [Use the flow editor](/how-tos/pipelines/flow-editor).
- **Toolkit or MCP connection**: configuration, credential, and which tools are enabled. See [Use credentials](/how-tos/credentials-toolkits/how-to-use-credentials).

## Creating a new one

<Note>
Not available yet: creating a new agent, pipeline, toolkit, or MCP connection directly from a chat participant menu — the menu only lists existing items to attach, with no "create new" option. Use the standalone create pages instead: [Create an agent](/menus/agents), [Create a pipeline](/menus/pipelines), [Create a toolkit](/menus/toolkits), or create an MCP connection from the same toolkits area. Once created, come back to chat and attach it as a participant. (tracked in [#867](https://github.com/elitea-ng/elitea-platform/issues/867))
</Note>
