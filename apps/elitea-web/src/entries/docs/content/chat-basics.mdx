A conversation is the unit chat is organized into: a list of messages
between you and one or more participants (the default assistant, or an
agent you have added).

<Info>
Conversations belong to a project, not to you personally — a conversation
started in a shared project is visible to anyone with access to that
project, the same as any other project resource.
</Info>

## Starting a new conversation

Open **Chat** and either continue the most recent conversation in the
current project or start a new one. Each conversation keeps its own message
history and its own set of attached context.

## Adding an agent to a conversation

<Badge>Optional</Badge>

An agent is an assistant configured with a specific prompt, model, and set
of tools. Add one as a participant to route messages to it instead of (or
alongside) the default assistant.

<Check>
A conversation can have more than one agent participant at once — each
message still goes to whichever participant you address it to.
</Check>

## Sharing a conversation

A share link makes one conversation readable by anyone who has the link, with
no sign-in required. The recipient sees the messages as they existed when the
link was generated; they cannot post new messages or see other conversations
in the project.

<Warning>
Anyone with a share link can read that conversation for as long as the link
stays valid — treat it like any other link to information you would not
want indexed publicly.
</Warning>

See [Quick start](/quick-start) for signing in before you get to a
conversation at all.
