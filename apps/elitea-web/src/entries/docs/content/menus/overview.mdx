Every menu in Elitea shares the same shell: a sidebar for navigation, a project selector, and a consistent set of list, search, and organization controls. This page covers what is common; each menu's own page covers what is specific to it.

<Screenshot id="overview-sidebar" alt="Elitea sidebar with the main menu items and project selector" />

## Sidebar

The sidebar gives you access to every menu:

- **Chat** — conversations with models, agents, pipelines, toolkits, and MCP servers.
- **Agents**, **Pipelines**, **Skills** — the entities you build and manage.
- **Toolkits** — integrations with external services, plus MCP servers when your administrator has turned on MCP menu exposure.
- **Apps** — installed applications (DeepWiki, Inventory) and the catalog of applications you can request access to.
- **Credentials**, **Artifacts** — supporting resources: authentication and file storage.
- **Catalog** — the shared library of published agents and skills.
- **Settings** — project and personal configuration.

At the bottom of the sidebar you'll also find a **?** Help Center button, a notification bell, and your user profile.

## Project selector

Use the project selector at the top of the sidebar to switch between your **personal project** — visible only to you — and any **team projects** you belong to, where entities are shared and collaboratively managed according to each member's role.

## Common list controls

Most menus (Agents, Pipelines, Skills, Toolkits, Credentials) share the same dashboard pattern:

- **Card view** and **table view**, toggled from the top of the list.
- A **search box** scoped to the current menu — search does not span menus.
- **Tag filters** to narrow the list by category.
- **Pinning** — pin an item to keep it at the top of its list.
- **Sorting** (table view) by name, created date, type, or author.
