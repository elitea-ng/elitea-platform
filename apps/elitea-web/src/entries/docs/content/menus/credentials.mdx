---
title: "Credentials"
description: "Securely store and manage the authentication details toolkits and AI providers use to connect to external services."
---

A credential holds the authentication information — API key, token, username/password, or similar — a toolkit or AI provider needs to connect to an external service. Storing credentials centrally means you configure them once and reuse them across multiple toolkits and agents.

<Screenshot id="credentials-list" alt="The Credentials dashboard for the current project" />

## Create a credential

<Steps>
  <Step title="Start creation">Select **+ Create** from the Credentials page.</Step>
  <Step title="Pick a type">Choose a credential type from the categorized list (code repositories, project management, testing, and more — matching the [toolkit catalogue](/reference/toolkit-catalogue)).</Step>
  <Step title="Fill in details">Enter **Display Name**, a unique **ID**, and the type's specific fields — a URL, a username, and a key or token.</Step>
  <Step title="Test (optional)">Where offered, select **Test Connection** to verify the values before saving.</Step>
  <Step title="Save">Select **Save**.</Step>
</Steps>

<Warning title="Prefer secrets for sensitive values">
When a field accepts a secret, use [Settings › Secrets](/menus/settings/project-settings#secrets) instead of typing the value directly — the field's dropdown lets you create a new project or private secret inline.
</Warning>

## Project vs. private credentials

A credential can be shared with the team (visible to any project member configuring a toolkit) or kept private to you. Team-shared toolkits sometimes require each member to hold a matching private credential — see the shared-credential note on the [Toolkits](/menus/toolkits#shared-credentials-in-team-projects) page.

## Edit or delete a credential

Open a credential from the dashboard to update its name or parameters and select **Save**, or use the delete action and confirm by typing its name. Deleting a credential in use will break the toolkit or agent that depends on it.

## Assign a credential

When creating or editing a toolkit or an AI provider configuration, open its **Credentials** dropdown and select an existing credential, or create one inline.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Authentication fails">Check that the key, token, or password is correct, current, and free of stray whitespace, and that your account still has access to the target service.</Accordion>
  <Accordion title="Credential is missing from a list">Confirm you are viewing the right project, and that the credential has not been deleted by another team member.</Accordion>
</AccordionGroup>
