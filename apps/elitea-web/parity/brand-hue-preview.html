Elitea brand hue — decision preview

Generated by node scripts/gen-hue-preview.mjs from src/shared/brand/tokens/default.pack.json using the shipping derivation (src/shared/brand/color.ts). Columns 2 and 3 show what a brand pack that states only brand.hue renders. Derivation is per scheme against that scheme's own primary.main anchor, so each candidate leaves one scheme byte-identical to today and repaints the other — which is precisely the choice being made.

This file is a decision aid, not a parity artefact. The default pack states every token verbatim, so nothing here changes what ships until the operator picks a hue AND a pack chooses to omit tokens. Swatches with alpha are drawn over white; on the real surface they composite over the scheme background shown in the panel above them.
