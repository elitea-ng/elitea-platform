Read and manage Aha! features, ideas and releases. It's listed under the **project management** category in the toolkit type picker.

## Prerequisites

- An account at Aha! with permission to issue an API token or credential, saved in Elitea as a **`aha`** credential (`/credentials/create-credential/<type>`).

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **project management** category, or search for "Aha!".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **aha** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>
