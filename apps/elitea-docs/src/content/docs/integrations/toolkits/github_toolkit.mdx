Read and write files, branches, issues and pull requests in a GitHub repository. It's listed under the **code repositories** category in the toolkit type picker.

## Prerequisites

- An account at GitHub with permission to issue an API token or credential, saved in Elitea as a **`github`** credential (`/credentials/create-credential/<type>`).
- If you plan to index content for retrieval: an embedding model, configured under AI providers.

## Connect the toolkit

<Steps>
<Step title="Open the toolkit type picker">
In the left navigation, open **Toolkits**, then select **New**. Filter the type picker by the **code repositories** category, or search for "GitHub".
</Step>

<Step title="Pick or create a credential">
Under the credential field, choose an existing **github** credential, or select **Create credential** to add one without leaving the form.
</Step>

<Step title="Add indexing settings (optional)">
If you plan to index this source, set an **embedding model**. Indexes are kept in the platform's vector store, so there is no vector-storage setting to pick. Leave it empty to use the toolkit without indexing.
</Step>

<Step title="Save">
Name the toolkit and select **Create**. It's now available to attach to agents, pipelines and conversations in this project.
</Step>
</Steps>

## Common issues

<Note>
The Indexes tab only appears when the configured worker can run this type's `index_data` tool; if the worker can't, the tab is hidden and shows the worker's refusal message. `index_data` itself can't be run from the Test tools pane — use the Indexes tab.
</Note>

<Note>
There's no connection check on this form. Save the toolkit, then run one read-only tool from the editor's Test tools pane to confirm the credential works before attaching GitHub to an agent.
</Note>
