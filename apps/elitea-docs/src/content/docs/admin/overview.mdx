The admin console is a separate application at `/admin/app`, distinct from the main Elitea app. It is where an administrator manages the deployment as a whole: users, projects, authentication, the LLM proxy, budgets, branding, and platform-wide configuration.

## Open the admin console

Sign in to Elitea normally, then navigate to `/admin/app`. The console renders only if your account holds at least one administration-mode permission — otherwise you see an access-denied screen instead of an empty shell. Every individual page still enforces its own permission on the server on every request; the console's own check only decides whether it is worth rendering the navigation at all.

<Note>
There is no LiteLLM section. LiteLLM has been replaced by a standalone gateway service; its former admin screen is gone rather than kept as a dead link. A "Service Descriptors" entry is present even though the legacy admin UI never linked to it — it now answers honestly that this platform has no external provider hub, which is more useful than a page nothing could reach.
</Note>

## What each page can and cannot decide

`window`-injected permission flags in the console are presentation only: they decide what the sidebar shows, never what a request is allowed to do. Every read and write is re-authorized on the server against the actual permission that route requires. A typed URL to a page your account cannot use still reaches it — and still gets refused there.
