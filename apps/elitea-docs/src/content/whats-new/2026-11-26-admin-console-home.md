## The admin console opens on Home

The admin console no longer opens on **Users** for everyone. It opens on **Home**: one card for each area your administration roles open, and the queues waiting for you (app requests, connector requests and delegations awaiting review) with how many requests each holds. A person whose roles open one area goes straight to it, and a person whose roles open none sees whom to ask for access. See [Admin console overview](/admin/overview#home).
