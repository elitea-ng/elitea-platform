## The Workshop lists: one list, every control in the side panel, multi-select

**Agents**, **Pipelines**, **Skills** and **Toolkits & Indexes** and **MCPs** no longer have a toolbar row or status tabs (All, Drafts, Published, Moderation, Approval, Rejected: three of them could never hold an agent). Each agent and pipeline shows a **Draft** or **Published** badge, and **Status** and **Origin** (own or forked) are filters in the **List** tab of the side panel, with how many items each holds, counted by the server over the whole project and offered only when they occur. The same tab holds the search (`/` or ⌘F), **+ New**, **Import**, sort, the card/table switch and the folders. The panel is open by default on wide windows and remembered per page. When it is closed or a drawer, a bar above the list shows the search and active filters with **Clear** and **+ New**. Select several items (table checkboxes, ⌘-click on a card) to **Add tag**, **Export** or **Delete** them together. Old `/agents/drafts` and `/agents/published` links open the list with that status filter on. The agents and pipelines lists now load a server page at a time with **Load more**, so every item the counts claim is reachable (they used to stop at the first 20), and sorting runs on the server. **Status** is a multi-select: a link with several statuses applies all of them. After a partly failed bulk action, only the items it failed on stay selected, with the error. **Upgrade Main and the web app together** (the list response gains `facets`, and the list accepts `status` and `origin`).
