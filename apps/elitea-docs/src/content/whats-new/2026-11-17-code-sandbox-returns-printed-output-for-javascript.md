## Code sandbox returns printed output for JavaScript, TypeScript and Rust

`run_code` now returns what a JavaScript, TypeScript or Rust program printed, as `output`, cut at 20,000 characters like Python's streams. The Data Analysis `run_analysis_code` tool is now a `code_execution` tool for approval rules, like `run_code`.
