## The Mac desktop app comes as a disk image

The macOS download on each release is now a disk image, `Elitea-<version>-macos-arm64.dmg`, in place of the zipped app. Open it, then drag the app onto the **Applications** folder in the window that appears. The disk image is signed and notarised, so it opens without a warning, also offline.

The installer package, `Elitea-<version>-macos-arm64.pkg`, is still on the release for device management. Apple silicon (M1 or later) only, as before.

See [Managed devices](/admin/managed-devices#install-on-a-mac-yourself).
