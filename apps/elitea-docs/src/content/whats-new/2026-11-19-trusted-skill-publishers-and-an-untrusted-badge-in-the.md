## Trusted skill publishers, and an Untrusted badge in the skills list

An administrator can name projects whose skills every project trusts: **Features › Skill Publishing › Trusted Skill Publishers**. A skill added from one of them is applied as an instruction with no per-project review, and its editor says so. Skills from any other project stay quoted data until your project trusts that exact version. The Skills list now marks a skill from another project that your project has not trusted with an **Untrusted** badge. A message sent again after a pin was removed in between is refused, as a pick of that skill is. Client contract 1.64. See [Use a skill in chat](/menus/skills#use-a-skill-in-chat).
