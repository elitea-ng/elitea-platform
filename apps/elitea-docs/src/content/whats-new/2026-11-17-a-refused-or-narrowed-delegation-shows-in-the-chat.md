## A refused or narrowed delegation shows in the chat

When an agent calls another agent and the run refuses the delegation (no approved grant, or the toolkit is outside your own access) or runs it without something the approved grant no longer covers, the chat now says so at the called agent, on web, desktop and mobile: "Agent1 could not use git from Agent2. This delegation is not approved." An editor of the calling agent gets **Review delegation**; everyone else sees who to ask. See [Notices in the chat](/admin/enterprise-controls/least-privilege-and-trust#notices-in-the-chat). Nothing that runs today changes.
