## Team work threads on the web and mobile

A desktop **Local work** thread with several agents, opened in the web app or the mobile app, now shows its team: each agent with **Local** or **Cloud**, and **Lead** on the lead. The view is read-only; you change the team in the desktop app. An answer whose turn ran a command outside the sandbox is marked **Ran outside the sandbox**. See [Viewing a team thread on the web and mobile](/how-tos/chat-conversations/desktop-multi-agent#viewing-a-team-thread-on-the-web-and-mobile).
