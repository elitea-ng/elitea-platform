## The GitHub toolkit lists workflow runs

The GitHub toolkit has a new **Get workflow runs** tool. It lists recent GitHub Actions runs, newest first: 10 by default, up to 100. It can show one workflow's runs, named by its ID or file name, and filter by branch, status and event. Each run carries the ID that **Get workflow status** and **Get workflow logs** take. A workflow or repository that does not exist is answered with an error message. See [Finding workflow runs](/integrations/toolkits/github_toolkit#finding-workflow-runs).
