## Try opens on your default model; Try, Use in a chat and Add to a conversation for skills

**Try it** on a skill now opens a chat on your project's default model with no tools, so the first message just works. It is on the Marketplace listing and card, in the row menu of your own skills, and in the skill editor (**Test skill**, which reads **Save to try** while there are unsaved edits). **Use in a chat** pins a skill to a new or an existing conversation, and **Add to a conversation** copies a listing version into the project and pins the copy. The listing page says a Marketplace skill is untrusted until you add and trust it. In the composer, the skill picker marks untrusted and pinned skills and has **Pin to this conversation**, and the mobile app gets `/skill` with the pinned skills first. Local desktop threads pin skills too: see the next entry. See [Try a skill](/menus/skills#try-a-skill).
