## The `/` list starts with Skills; Untrusted shows in every skill list; a forked local thread keeps its pinned skills

Typing `/` in a chat now lists **Skills** first, even when the chat has no toolkit: choose it to open the skill picker (it writes `/skill `, or `~` when the `/` is not at the start of a line). The skills list now says which skills are untrusted (written in another project and not yet trusted by yours) in the same read, so the **Untrusted** badge also shows on the mobile app, on skills that are not pinned yet, and the web picker no longer asks the server once per skill. On the desktop app, forking a local thread copies its pinned skills to the fork, so the forked conversation keeps applying them. Client contract 1.63. See [Use a skill in chat](/menus/skills#use-a-skill-in-chat).
