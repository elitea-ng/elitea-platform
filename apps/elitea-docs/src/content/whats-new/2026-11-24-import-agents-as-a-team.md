## Import and export a team of agents

A team now travels as one zip: a `team.yaml` and an `.agent.md` file for each member. On the Teams switch of the Agents page, select **Export** on a team. To bring it into a project, select **Import** on the Agents list and choose the zip: the summary names the team and its lead, and one confirm creates every agent, its toolkits and skills, and the team. Nothing is created if anything cannot be: an agent name already in the project, a taken team name or a toolkit the file does not carry is named in the dialog, so you can fix the file and try again. Imported agents are now linked to the toolkits their file carries. See [Import and export entities](/how-tos/agents-pipelines/import-export).
