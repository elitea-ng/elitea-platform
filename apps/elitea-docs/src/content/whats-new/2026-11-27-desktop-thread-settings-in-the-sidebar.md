## Desktop threads: a calmer header and composer, thread settings in the sidebar

A Local work thread's title bar now holds only its name, the one run status while something runs, and **⋯**. The row under the message box holds **+**, the mode by its name, **To:**, **∞ To completion** and **Send**. In a thread of several agents, **To:** is a menu: address the message to an agent, or open **Manage participants…**.

Everything else moved to the **Participants** tab, under **Thread settings**, each with its value: **Workspace** (**Work in** and **Send to cloud**), **Sandbox**, **Sub-agents**, **Step limit**, **Models** and **Context**, then **Respect AGENTS.md**. The team notice above the composer is one line with **Learn more**, and you can hide it for the thread. **Turn off** in the Full auto line reads in light and dark themes.

Each agent now has its own model in the thread: choose **Model in this thread…** in the agent's menu in the **Participants** tab. The row shows the model only when it is not the agent's own. A model chosen for the whole thread before stays with the thread's lead, or its one agent. In a web chat with several agents, **Model in this thread…** in an agent's menu opens that agent's model settings for the conversation.

The mode, **To completion**, **Respect AGENTS.md** and the models you choose before the first message now go with the thread it creates, also in a new worktree. Before, a new worktree's thread started in **Act**. **Full auto** goes with it too, for that thread only. See [Thread settings](/menus/settings/desktop-account-menu#thread-settings) and [Choose a model for an agent](/how-tos/chat-conversations/desktop-multi-agent#choose-a-model-for-an-agent).
