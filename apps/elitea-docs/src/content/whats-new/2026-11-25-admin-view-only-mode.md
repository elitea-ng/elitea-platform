## Every admin page has a view-only mode

When your roles let you read an admin page but not change it, the page now says so with a **View only** notice under its title, and names the roles that can change it. Every control that would change something is still on screen but disabled, and its tooltip says why. Search, tabs, filters, paging and detail views keep working. This covers every page of the console: People and access, Projects, Models and spend, Agents and governance, Security and Platform. Buttons that used to disappear for a role without the permission, such as **Create secret** or **New role**, are now shown disabled, so you can see what the page offers and whom to ask. Revealing a secret's value and downloading the branding package are reads, so they keep working. See [View-only pages](/admin/overview#view-only-pages).
