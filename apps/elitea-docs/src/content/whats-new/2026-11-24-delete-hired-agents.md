## Hired agents delete cleanly

Deleting an agent hired from the Marketplace, or one that uses sub-agents, now also deletes the private sub-agent copies it carries. Those copies, listed as drafts, used to refuse every delete. A copy left behind by an earlier release can now be deleted on its own. When a delete is refused, for example because the agent is published, the dialog tells you why.
