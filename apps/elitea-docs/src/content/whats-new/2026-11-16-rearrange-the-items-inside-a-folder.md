## Rearrange the items inside a folder

On the **Agents** and **Pipelines** lists, an open folder is sorted by **Folder order** by default: drag a card or row onto another one, use the keyboard (**Space**, arrow keys, **Space**), or choose **Move up** / **Move down** in the folder icon's menu. Every member sees the same order. See [Order inside a folder](/how-tos/entity-management/organizing-entities/#order-inside-a-folder).
