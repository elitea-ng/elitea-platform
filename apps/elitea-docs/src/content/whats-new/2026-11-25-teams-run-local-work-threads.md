## Teams can run desktop work threads

In the desktop app, a saved team can now run a **Local work** thread: open the agent chip, choose **Run as a team ›** and the team. The new thread holds every agent of the team on the version the team saved, and its lead, as a team chat does. A message that names no agent goes to the lead; **@Name** addresses another member. Every member works on this computer with the folder; an agent a member calls as a tool runs in the cloud without the folder, and the composer says so. When the thread is sent to the cloud, it continues on the lead (or, without one, on the agent of the last local turn), and messages written to it there are routed the same way. See [Run a thread as a team](/how-tos/chat-conversations/desktop-multi-agent#run-a-thread-as-a-team).
