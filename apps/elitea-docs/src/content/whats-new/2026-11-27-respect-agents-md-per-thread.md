## AGENTS.md in the Participants tab, with a switch per thread

A desktop Local work thread no longer shows "AGENTS.md applied" under every message. The **Participants** tab lists the folder's project instructions once, under **Project instructions**, with a **Respect AGENTS.md** switch. It is on by default when the folder has an `AGENTS.md`; turn it off and the thread's next turns run without the files, for every agent of the thread, and the tab says **AGENTS.md ignored in this thread**. The choice stays with the thread across reopening it and restarting the app. Each answer records whether the files were applied, and the web and mobile app show **AGENTS.md applied** or **AGENTS.md ignored** on it. See [Project instructions](/how-tos/chat-conversations/desktop-multi-agent#project-instructions).
