## Agent versions, per-agent toolkit tools and forks that keep their toolkits

**Save as version** now copies the agent's toolkits (with their selected tools) and sub-agents to the new version, and adding a toolkit or agent on a version other than the default now attaches it to that version, not to the default one. Importing the zip of an agent exported with several versions creates one agent with those versions, not one agent per version. The Compare versions window is wider and no longer cuts text. Every toolkit card on an agent now has **Show tools**, where you choose which of the toolkit's tools this agent uses without changing the toolkit. Forking an agent into another project now forks its toolkits (without credentials or secrets) and its nested agents with it. The Workshop list shows **On probation** on an agent the workforce policy hired, with **Undo hire** in the table view for 14 days, and an automatic hire now gets the listing's avatar. No operator action is needed.
