## Review delegation opens the delegation, and a refused pipeline node shows its notice

The **Review delegation** link in a chat notice now opens the review window of that exact delegation on the calling agent's Tools panel, instead of only the agent. The mobile app lists that delegation first and marks it. A pipeline node that runs a saved pipeline and is refused now shows the same **Delegation refused** card before the run fails, where it showed only the generic failure. In `report` mode nothing is shown, because nothing was refused; the run step records it. Upgrade the worker and the web app together. See [Notices in the chat](/admin/enterprise-controls/least-privilege-and-trust#notices-in-the-chat).
