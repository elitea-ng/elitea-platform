## See what each agent is doing

A conversation with several agents now says what each one is doing: **Thinking**, **Writing**, **Running jira_get_issue**, **Waiting for you** or **Waiting for CI Doctor**. The labels show in the participants list on the web and in the desktop app (including desktop work threads, where a local command shows only its program's name), and next to the live reply on mobile. Only the agent that is working moves; with **Reduce motion** turned on, nothing moves and the labels still change. Screen readers announce the changes politely. See [See who is working](/how-tos/chat-conversations/desktop-multi-agent#see-who-is-working).
