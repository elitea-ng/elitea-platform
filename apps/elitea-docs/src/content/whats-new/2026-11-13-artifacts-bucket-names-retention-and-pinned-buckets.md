## Artifacts: bucket names, retention and pinned buckets

A bucket name you type with capital letters is lowercased as you type, so **Create bucket** no longer fails silently. **Retention (days)** is now on the New bucket form too, not only when you edit a bucket; leave it empty on a new bucket to use the project's default retention. Bucket names follow the server's rule (a lowercase letter first, 2 to 63 characters). A pinned bucket keeps its pin icon visible in the list, and the text cursor shows in the Code and Canvas editors on the dark theme.
