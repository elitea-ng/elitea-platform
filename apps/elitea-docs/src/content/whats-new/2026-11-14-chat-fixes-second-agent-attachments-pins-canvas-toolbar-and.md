## Chat fixes: second agent, attachments, pins, canvas toolbar and agent cards

Adding a second agent to a chat no longer fails with a "version not found" error, and the chat no longer stays loading. A file you attach now stays on the message after you send it. A pinned folder moves ahead of the other folders, and pinned folders and chats show a pin icon beside the name. The formatting icons in the canvas document editor stay visible when you hover them, in the light and the dark theme. Agent cards in the Agents hub have a visible border again, and a click on a card's heart adds a like without opening the agent.
