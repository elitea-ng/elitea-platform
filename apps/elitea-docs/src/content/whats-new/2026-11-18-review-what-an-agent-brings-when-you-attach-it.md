## Review what an agent brings when you attach it

Choosing an agent or pipeline in the Tools panel now opens **What *name* will be able to use**: its toolkits and tools, the credentials they use, its data classes and the hosts it can reach, and the agents it calls. **Approve and attach** attaches it and approves the delegation in one step; untick a toolkit to leave it out. What you cannot access is shown disabled with the reason and stays out. Under the governed profile the button is **Request approval** and a different approver decides. Each attached agent shows **Delegation approved**, **Delegation not approved**, **Awaiting approval** or **Needs re-approval**, with **Review delegation**. The desktop app has the same window; the mobile app lists an agent's delegations and lets an editor approve or revoke them. An approver's access is now checked per toolkit (including the folder access rules) and per credential. Upgrade Main and the web app together. See [Attach a specialist agent](/how-tos/agents-pipelines/attach-a-specialist-agent).
