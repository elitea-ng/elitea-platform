## Folders for agents, pipelines, skills, toolkits and MCPs

Each of the **Agents**, **Pipelines**, **Skills**, **Toolkits & Indexes** and **MCPs** lists now has project folders, shared with every member of the project. Open **Filters** to find the **Folders** section: create a folder with **+**, select one to show only its items, and use a folder's **⋯** menu to **Rename**, **Move up**, **Move down** or **Delete…** it (its items go back to the list; nothing else is deleted). Put an item in a folder with the folder icon on its card, or in the **Folder** column of the table view. There is no new permission: creating a folder needs the list's create permission, and renaming, reordering, deleting and moving need its update permission. **Run the migrations** (one tenant migration) and upgrade Main and the web app together. See [Organize agents, pipelines and toolkits](/how-tos/entity-management/organizing-entities#folders).
