## Delegation, Marketplace and pinned-skill follow-ups

A delegation notice that streams live now names the agent that tried to delegate, as the reloaded answer already did, instead of the runtime label. An approver of an agent attach is now asked per toolkit which credentials they stand behind: a credential reference that one toolkit's use grant covers no longer counts as held for another toolkit that names it. A "Review delegation" link that names an agent with no grant is dropped from the address once the grants have loaded, and a pipeline node refused for delegation offers its notice again if the first publish fails. The daily Marketplace pass now marks as dismissed any hire whose agent or skill is gone (deleted skills, the workforce ladder, a deleted project), so active hires, retention and the dismissal rate no longer overcount. "Add to a conversation" checks the conversation before it forks a listing into the project, so a full conversation leaves no stray copy, and on the desktop app a pin that would take a thread's pinned skills past 64 KiB is refused at the pin instead of at every later turn.
