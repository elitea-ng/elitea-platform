## Tokens carry no administration rights by default

Your administration rights now depend on how you signed in. A browser session has all of them. A new personal access token has none, even when you are an administrator. A token you made before the earlier upgrade keeps your rights if you were an administrator then. On desktop and mobile you can still work during a maintenance window and moderate the Marketplace, but you cannot call any administration API. Agent runs and project system tokens have no administration rights. To do administration work, use the console in your browser. See [Which credential carries which administration rights](/admin/authentication#which-credential-carries-which-administration-rights).
