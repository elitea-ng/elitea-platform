## Agents hand off to each other in desktop team threads

In a desktop **Local work** thread run as a team, an agent can now hand the work to another agent of the thread, as it already could in a cloud conversation. The hand-off shows as a side message with both avatars, the next agent answers, and **Stop exchange** and **×** stop a hand-off chain. The receiving agent reads the hand-off as another agent's message, not yours: in a trusted folder its commands are always asked, even with **Bypass approvals**. The cloud's limits stop an exchange that goes in circles, and an agent that runs in the cloud answers a hand-off but cannot hand on. See [Agents hand off to each other](/how-tos/chat-conversations/desktop-multi-agent#agents-hand-off-to-each-other).
