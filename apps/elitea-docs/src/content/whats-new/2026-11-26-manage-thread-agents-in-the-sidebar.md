## Manage a desktop thread's agents in the Participants tab

In the desktop app, a **Local work** thread's agents are now managed in the **Participants** tab of the right sidebar, as a chat's participants are, instead of in nested menus of the composer's agent chip. The tab lists every agent of the thread with its version, **Local** or **Cloud**, **Lead** on the lead and what it is doing now. **Add an agent**, **Add a cloud agent** and **Add team** open a search list. Before a new thread's first message, **Make lead**, **Remove from thread** and **Change** set it up. The agent chip now says who your message goes to, for example **To: Reviewer (lead)**, and opens the tab. See [Add an agent to a thread](/how-tos/chat-conversations/desktop-multi-agent#add-an-agent-to-a-thread).
