## Only a sign-in can create a personal token

A personal access token can no longer create another personal token, and neither can the token an agent run uses. Create tokens in the web app. The desktop app still creates them, except for an account with administrator permissions, which creates them in the browser. See [Personal tokens](/menus/settings/personal-tokens#where-you-can-create-a-token).
