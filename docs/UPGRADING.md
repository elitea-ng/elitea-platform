# Upgrading

Changes that need an operator to act when a deployment moves to a newer
release. Each entry says what changed, who is affected, and what to do.

**Read the entries on the docs site:**
[Deployment › Upgrading](https://elitea-ng.github.io/elitea-platform/deployment/upgrading/)
(`/docs/deployment/upgrading/` in a running deployment). The page shows every
entry, the newest first. Read the entries between your version and the new one
before you upgrade.

A chart error or a comment that says "see docs/UPGRADING.md, "<title>"" names
the entry by its title: find that title on the page.

**The entries are in [`docs/upgrading/`](upgrading/), one file per change.**
To add an entry, add a new file there. [`docs/upgrading/README.md`](upgrading/README.md)
gives the template and the rules. Do not edit this file:
`scripts/ci/check-upgrading-fragments.mjs` refuses a change to it.
