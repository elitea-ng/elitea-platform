# The legacy administration items cannot be removed before their announced date (#2590, ADR-0059 R0.14b)

**What changed.** CI now holds the end of the legacy administration items to
a date. The items are the permission names `runtime.plugins` and
`configuration.governance`, `inherit` administration access on personal
access tokens, and serving a dangerous administration request that has no
reason. They end on one sunset date, which is set in the code once the
replacements (the sealed sign-in and the reason handling) have shipped. The
date is at least 90 days after the replacements shipped. A release that
removes the items must come after that date, and at least two stable minor
releases must follow the release that shipped the replacements.

No date is set yet. An upgrade note will name the date when it is set.

**Operator action.** None. Nothing in a deployment changes. The removal
cannot arrive in a release before the announced date, so you have the full
notice period to move roles and tokens off the legacy items.
