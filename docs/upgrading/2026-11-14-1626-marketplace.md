# Web, desktop and mobile: the Catalog (Agent HUB) is now the Marketplace (#1626, ADR-0051)

The shared library of published agents and skills moved from `/elitea-catalog`
(and the older `/agents-hub`) to `/marketplace`, with listing pages at
`/marketplace/{kind}/{listingId}`. It is now a row in the sidebar on the web and
in the desktop app, not an entry in the account menu.

**Who is affected:** people with bookmarks or shared links to the old addresses,
and anything that links to them.

**What to do:** nothing is required. `/elitea-catalog` and `/agents-hub` redirect
and keep what they carried: `?agentId=<id>` opens that agent's listing page and
`?tab=skills` opens the skills. Update links you control to `/marketplace` when
convenient. There is no backend, API, migration or configuration change.
