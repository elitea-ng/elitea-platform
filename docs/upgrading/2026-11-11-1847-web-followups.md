# Web: Teams tab paging, team agent search, one sub-agent lane (#1847, #1846, #1924, #1910, #1895)

Web and desktop client changes only. No API, contract or migration change.

- **The Teams tab pages (#1847).** It used to show at most 200 teams. It now loads 200 at a time with the list
  route's `offset`, shows "Showing N of M teams" when there are more, and **Show more** loads the next page.
- **The team editor searches agents (#1846).** **Add an agent** used to list only the first 100 agents of the
  project. It is now a search: what you type is sent as the applications list's `query`, so any agent can be found.
  It shows up to 50 matches and says when there are more.
- **One sub-agent lane (#1924).** The chat answer and the desktop transcript draw the same lane. The chat answer now
  also shows a finished sub-agent's steps and tokens.
- **Desktop local sub-agent avatars (#1910).** A local sub-agent whose spawn profile names an avatar now shows an avatar (the brand mark; avatar keys name no image yet) in
  its lane. The lane also keeps the brief's digests and references from `subagent_started` in the thread history.
- **The agent editor shows a refused conversation-history setting (#1895).** A save refused with
  `context_block_invalid` is now shown under the **Conversation history** field instead of being dropped.
- **Who is affected.** People using agent teams, sub-agents, and the agent editor. Nothing to do.
