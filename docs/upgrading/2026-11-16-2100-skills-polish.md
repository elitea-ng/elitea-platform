# Skills: icon upload accepts raster images only (issues 2100-2115)

**What changed.** The skill icon upload now judges the file by its bytes, not its name. It accepts
PNG, JPG, GIF, WEBP, BMP and ICO, up to the existing size limit, and answers `400` with a message
naming those formats for anything else (SVG and TIFF included, an empty file too). Before this an
upload of any kind was stored as `.png`. The publish check no longer reports "Validation token is
invalid" for a skill that meets the requirements. No migration and no new setting.

**Who is affected.** Anyone who uploaded a skill icon in a format outside that list through the API.
Icons already stored are served as before.

**What to do.** Nothing. Upgrade Main and the web app together.
