# Image generation is billed by size and quality, and admitted against the budget (issue 1969)

- **What changed.**
  - **Per-image prices in the catalogue.** Shared migration `0242_gateway_image_pricing.sql` adds
    `gateway.gateway_model_image_prices` (one row per model, size and quality) and five nullable columns on
    `gateway.llm_request_logs` (`kind`, `image_count`, `image_size`, `image_quality`, `pricing_source`). The price sync
    reads the LiteLLM per-image and per-pixel prices into the new table.
  - **Billing order for images.** Token usage from the provider pays first, as before. Without token usage, the gateway
    bills the images the provider returned at the catalogue price for the model, size and quality. Without a catalogue
    price, it bills the flat 0.04 USD estimate and marks the request-log row `fallback_estimate`.
  - **Admission.** Before the provider call, an image request is refused (HTTP 402, the usual budget error) when its
    estimated cost is more than what is left of the project or member budget. Before, the gateway refused only a budget
    that was already used up.
  - **New metrics.** `gateway_image_fallback_estimate_total` and `gateway_image_budget_refused_total`.
- **Who is affected.** Projects that use DALL-E, Imagen, Bedrock or fal.ai image models. Their cost changes to the list
  price: DALL-E 3 HD 1792x1024 was billed at 0.04 USD and is now 0.12 USD. DALL-E 2 256x256 was billed at 0.04 USD and is
  now 0.016 USD. A project close to its budget can see a 402 on an image call that would have passed before.
- **What to do.** Apply the shared migrations (`elitea-migrate`) before or with the new gateway and scheduler. A gateway
  that runs before the migration bills the estimate and keeps working. A scheduler that runs before it skips the image
  prices and still refreshes the token prices. Watch `gateway_image_fallback_estimate_total`: when it rises, add a price
  for the model in `gateway.gateway_model_image_prices` (set `price_overridden = true` to keep it through the next sync).
