================================================================================
UPGRADE WARNING: the Rust worker is now the default, and it runs here with
PYTHON indexing (worker.indexingRuntime is not "rust").
  * Agents running on the Rust worker CANNOT search the existing (Python-era)
    indexes: their search_index and stepback tools read the Rust vector store,
    which starts empty. Until indexing is switched to Rust and the indexes are
    re-created, agents lose index search over everything indexed so far. Nothing
    is migrated between the two.
  * These toolkit types have no Rust implementation yet and are unavailable on
    the Rust worker: memory, vectorstore, sandbox, delta_lake, aws, localgit.
To keep today's behaviour, set worker.implementation: python.
To use Rust indexing, set worker.indexingRuntime: rust together with
vector.enabled=true (and vector.qdrant.apiKeySecret.name),
main.runtime.enabled=true and main.runtime.indexIngestDispatch.enabled=true; the
render names anything missing, then re-create your indexes.
================================================================================
