# Tests that this repository accepts as skipped, and the reason for each.
#
# WHY THIS FILE EXISTS (#423)
#
# `go test ./...` prints `ok` for a package whose tests all called `t.Skip`.
# Eighteen suites did that on every CI run. The job was green and the coverage
# was zero, so nobody saw it. scripts/go/skip-ledger.py now records each skip
# and scripts/go/skip-gate.py compares the record against this file. With
# ELITEA_REQUIRE_DECLARED_SKIPS=1 — which .github/workflows/ci-go.yml sets — a
# skip that this file does not explain FAILS the run.
#
# Format, one skip per line, TAB separated:
#
#   <package import path><TAB><test><TAB><reason>
#
# <test> may be `*` for the whole package, or end in `/*` to cover a test and
# its subtests. The reason is not optional. A declaration with no reason is
# the same silent skip with a longer paper trail.
#
# BEFORE YOU ADD A LINE HERE, TRY THE OTHER THREE ANSWERS FIRST:
#
#   1. Give CI the service the test wants. A container is cheap. The three
#      isolated databases in ci-go.yml each revived a suite that had never
#      run.
#   2. Make the guard FAIL instead of skip when a "require" flag is on, as
#      ELITEA_REQUIRE_LEGACY_RBAC_POSTGRES_TEST does.
#   3. Delete the test if nobody intends to run it. A test that always skips
#      is not coverage; it is the appearance of coverage.
#
# A line belongs here only when the test needs something CI genuinely cannot
# give it: a private cookie file, a
# credentialed staging deployment, a pinned worker container, or a sibling
# repository.
