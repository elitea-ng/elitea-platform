# Changelog — `tallyctl`

All notable changes to this project are documented in this file. The format
is based on Keep a Changelog, and this project adheres to Semantic Versioning.

> Note: entries before 3.1.0 were generated by the old release script, which
> wrote dates as DD/MM/YYYY. Newer entries use ISO 8601 dates.

## [Unreleased]

### Added
- Experimental gRPC streaming export (behind `--experimental-grpc`).

### Fixed
- Flaky progress bar on narrow terminals.

## [3.2.0] - 2026-09-30

### Added
- Bulk export of audit events to CSV.
- `--since` flag for the `history` command.
- Support for PostgreSQL 18.

### Changed
- Default page size raised from 50 to 100. Clients that relied on the old
  default should now pass `--limit 50` explicitly.
- Progress output now goes to stderr instead of stdout.

### Deprecated
- The `--json-v1` output format; it will be removed in 4.0.0.

### Fixed
- Crash when the config file was empty.
- `--until` ignored the timezone offset of its argument.
  - Only affected builds on Windows.
  - Reported in #812.

### Security
- Bump bundled OpenSSL to 3.5.4 (CVE-2026-31337).

## [3.1.1] - 2026-09-02

### Fixed
- Memory leak in the file watcher.
- Wrong exit code (0 instead of 143) on SIGTERM.
- Typo in `tallyctl sync --help`.

## [3.1.0] - 2026-08-14 [YANKED]

Yanked because a cache migration bug could corrupt the local cache. Upgrade
directly to 3.1.1.

### Added
- Plugin hooks (`pre-sync`, `post-sync`).
- Shell completion for fish.

### Fixed
- Off-by-one error in the pagination of `tallyctl list`.

## [3.0.0] - 03/07/2026

### Changed
- **BREAKING:** the config file moved from `~/.tallyrc` to
  `~/.config/tally/config.toml`. Run `tallyctl migrate-config` once.
- Minimum supported Node.js version is now 22.

### Removed
- **BREAKING:** dropped support for the deprecated `v1` config format.
- Removed the `--legacy-auth` flag (deprecated since 2.4.0).

### Fixed
- Unicode file names are now preserved on export.

### Fixed
- Retry loop no longer spins when the server returns HTTP 429.
- `tallyctl doctor` now reports the correct config path.

## [2.9.4] - 11/06/2026

### Security
- Sanitise ANSI escape sequences in server-provided error messages.

### Fixed
- `--dry-run` no longer writes the lock file.
