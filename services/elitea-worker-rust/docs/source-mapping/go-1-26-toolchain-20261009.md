# Go 1.26 toolchain for the go.work modules

This record covers a toolchain and dependency change in the Go modules. It changes no Worker code. The Worker
documentation holds it because the delivery gate keeps every source mapping here. It closes the follow-ups of
[go-module-advisories-20261008.md](go-module-advisories-20261008.md) and of `go-module-advisories-20261009.md` (#1178).

## Business behavior and scope

The current platform (Python SDK, Pylon) is not involved: it has no Go modules. Nothing was ported.

The go.work modules built on the Go 1.25 series. Three sets of fixes could not be taken there:

| Advisory | Where | Fixed in | Outcome |
| --- | --- | --- | --- |
| GO-2026-6599, 6600 (`html/template`), 6604 (`os`), 6605, 6609, 6613 (`net/http`), 6607 (`crypto/tls`), 6608 (`net/textproto`) | standard library | go1.26.9, go1.27.2; **no 1.25 release** | **Fixed**: every module builds on 1.26, floor go1.26.9 |
| GO-2026-6603, 6610, 6611, 6612, 6617 (HTTP/2) | standard library (the HTTP/2 bundle in `net/http`) | go1.26.9; **no 1.25 release** (go1.27.2 for Go 1.27's relocated `net/http/internal/http2`) | **Fixed** by the same floor |
| GO-2026-6603, 6610, 6611, 6612, 6617 (HTTP/2) | `golang.org/x/net` v0.58.0 | v0.60.0, which declares `go 1.26.0` | **Fixed** in elitea-main, elitea-scheduler, `libs/go/observability`, `libs/proto/gen/go`, `gen/go`, `conformance/nativeclient` |
| GO-2026-6354, 6355 (`x/crypto/ssh`) | `golang.org/x/crypto` v0.55.0 | v0.56.0, which declares `go 1.26.0` | **Fixed**: v0.57.0 in elitea-main and elitea-scheduler |
| GO-2026-5932 (`x/crypto/openpgp`) | `golang.org/x/crypto`, every version | none | **No fix exists**; the guard test keeps the package unlinked |

go1.25.14, the newest 1.25 release, still carries all thirteen standard-library findings in the first two rows, and
every service calls most of them. No 1.25 release fixes them, so the move is a security change in its own right and not
only an enabler for the module bumps.

## Performance

- **Budget:** no request-path code changes. The toolchain move must not change round trips, writes or allocations
  that Elitea code makes.
- **Runtime change to know about:** Go 1.26 enables the Green Tea garbage collector by default
  (`GreenTeaGC: true` in go1.26.9's `src/internal/buildcfg/exp.go:88`). The gateway has already run on it since it
  moved to 1.26. No load benchmark was run for Main or the scheduler on the new collector. This is an open item, not a
  pass; `GOEXPERIMENT=nogreenteagc` at build time is the fallback if a regression shows.
- **Measured:** stripped `linux/amd64` binary sizes, built with `CGO_ENABLED=0 -trimpath -ldflags="-s -w"` as the
  Containerfiles do. Before is `origin/main` at `0def77b22` on go1.25.14; after is this branch on go1.26.9.

| Binary | Before | After |
| --- | --- | --- |
| elitea-main | 90,677,432 B | 91,680,930 B (+1,003,498 B, +1.1 %) |
| elitea-scheduler | 21,868,728 B | 22,065,314 B (+196,586 B, +0.9 %) |
| elitea-subapp-host | 11,595,960 B | 11,813,026 B (+217,066 B, +1.9 %) |

  The growth comes from the 1.26 runtime and standard library; subapp-host has no dependency change at all. `go

## Durability

Not applicable. The change touches no durable write, checkpoint, lease, receipt or migration, so it creates no crash
window. The real-PostgreSQL suites listed under Tests ran on the new toolchain.

## Resilience

- The standard-library fixes bound HTTP/1 and HTTP/2 servers and clients against hostile peers:
  - CONNECT desynchronization (6605, 6613);
  - unbounded `Range` header parsing (6609);
  - the MIME header memory limit (6608);
  - HTTP/2 trailer memory, window-update CPU, double flow-control refunds, the HPACK encoder race and malformed
    framing headers (6603, 6611, 6612, 6617, 6610).

  They apply to the HTTP and gRPC listeners and clients of Main, the scheduler and the sub-app host.
- x/net v0.60.0 carries the same HTTP/2 fixes for the gRPC transport, which uses `golang.org/x/net/http2` directly.
- The `html/template` (6599, 6600) and `crypto/tls` ECH (6607) fixes close parser edge cases. No Elitea code path
  changes.

## Security

- **Fixed:** GO-2026-6354/6355 (`x/crypto/ssh`), the x/net HTTP/2 set, and the thirteen standard-library findings
  above, in every go.work module.
- **Floor enforced in code:** `TestEveryShippedGoBuildIsAtOrAboveTheStdlibSecurityFloor`
  (`toolchain_floor_test.go`) fails if `go.work` or a shipped module declares less than go1.26.9, names a lower
  `toolchain`, or builds from a golang image outside the 1.26 series. `scripts/ci/check-gateway-toolchain.sh` reads the
  same constant for the gateway.
- **Guard kept:** `TestNoBinaryLinksAdvisoryPackagesWithoutFix` still bans `golang.org/x/crypto/openpgp`
  (GO-2026-5932, no fix). `ssh` left the list because the linked x/crypto now carries its fix.
- **Supply chain:**
  - No new dependency; only the version moves above.
  - Versions are exact in `go.mod`, and the Go checksum database verified every new `go.sum` hash during `go get`.
  - The builder images stay on the series tag `golang:1.26-trixie`; the `go` directive is the floor.
