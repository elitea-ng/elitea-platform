revision `b5113a12` (2026-08-07). This table compares **every served family** against upstream
`EliteaAI/elitea-sdk` `main` at `b3f1d7413019b2ba0d59c44bbcd2b03c0d83abeb` (2026-11-18): tool names and, for
each tool, the argument schema (names, required flags, types, enums, defaults, descriptions).

Method: the commit's source tree was imported (third-party packages stubbed), every wrapper class's
`get_available_tools()` was called (so the decorator-injected tools and per-call arguments are included,
and commented-out or unregistered tools are not), and each `args_schema.model_json_schema()` was diffed
against the snapshot entry of the same type. Index tools (`index_data`, `list_indexes`, `remove_index`,
`search_index`, `stepback_*`) are injected by the indexing base class and served by the index runtime
(ADR-0030), not by the families; their drift is listed once below, not per family.
