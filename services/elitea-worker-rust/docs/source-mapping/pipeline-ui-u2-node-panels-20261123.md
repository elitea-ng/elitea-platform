## 2. Deliberately Not Ported / Follow-Ups

- **Page-level `version_details.tools` attachment plumbing from canvas pickers:** `ProjectAgentPicker`, `ProjectToolkitPicker`, and `ProjectToolkitsMultiPicker` run with `attachedOnly` in node panels because `FlowEditor` / `FlowWrapper` / `PipelineEditor` do not yet expose a `version_details.tools` mutation callback in `FlowEditorContext`. Wiring `usePipelineToolAttachments` at the page shell level is deferred to Wave U2 integration (disjoint from `ui-u2-workspace-shell`).
- **Node YAML leave-confirmation modal (`NodeYamlLeaveModal.jsx`) and full-screen node YAML modal:** Deferred to a focused follow-up; per-node YAML currently validates inline with `role="alert"` and keeps last-valid graph state intact.
- **Real-browser Chrome / live-stack verification:** Deferred while Docker stacks are paused for host EKG builds; will be verified on Wave U2 integration spin-up.
