# meaning of each field are in internal_listener_checks_test.go.

# Administration data (provider, policy, identity and role data) is written
# through elitea-main's HTTP API only. An entry that can change it ("admin")
# must run Main's public route in process ("main-route"), and is listed in
# docs/ARCHITECTURE.md ("Internal listeners and administration data") with the
# caller identity it requires. Reviewing a new line means answering: what does
# it write, what decides it, who may call it. Those answers are declared here
# by the reviewer; the test cannot prove them, only that every method, route,
# listener and registration has been answered for.
